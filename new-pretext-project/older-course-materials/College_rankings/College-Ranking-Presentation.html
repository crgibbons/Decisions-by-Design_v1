Bloomberg data & methodology - 2021 ranking

  • 119 MBA programs (we will look at the first 84)
  • Five variables: Compensation, Learning, Networking, Entrepreneurship, Diversity
  • Weights for the categories are crowd-sourced
  • Surveys: students, alumni, recruiters
  • Key claim: It is intentionally not reproducible!
  • https://www.bloomberg.com/business-schools/methodology

Data collection and variable creation

  • Survey - each variable: 1-7
  • Raw scores weighted
  • Weighted sum: 1-7
  • Weighted sum is scaled to 0 - 100 (‘normalized’)
  • Minimum –> 0, Maximum –> 100
  • Transformation: \(T(x) = \frac{100}{x_{(n)} - x_{(1)}} (x - x_{(1)})\)

Dr. Jain’s main point

Transformation from 1-7 to 0-100 is linear (but he meant affine, not linear).

\[T(x) = \frac{100}{x_{(n)} - x_{(1)}} (x-x_{(1)})\] \[Z(x) = \frac{x - \mu_x}{\sigma_X}\] Dr. Jain’s claim:

\[Z(T(x)) = Z(x)\] Let’s see if that is correct.

Proof of Dr.Jain’s claim

For \(a>0\),

\[Z(ax) = \frac{ax - \mu_{ax}}{\sigma_{ax}} = \frac{ax - a\mu_{x}}{a\sigma_{x}} = Z(x)\] and for any \(c\in \mathbb{R}\), \[Z(x + c) = \frac{x+c - \mu_{x+c}}{\sigma_{x+c}} = \frac{x+c - \mu_{x}-c}{\sigma_{x}} = Z(x)\] Thus, \[Z(T(x)) = Z(\frac{100}{x_{(n)} - x_{(1)}} (x-x_{(1)})) = Z(x-x_{(1)}) = Z(x)\]

Dr. Jain’s main point is CORRECT.

“If the published ‘normalized scores’ on each index are simply a 0-100 linear re-scaling of the 1-7 raw data, as BBW’s email response indicates, then the published index scores can still be standardized before applying the index weights to them.”

We hope to have this:

\[ x_i \rightarrow Z(x_i) \rightarrow w_iZ(x_i) \rightarrow\sum_{i=1}^{5}w_iZ(x_i) \rightarrow T\left(\sum_{i=1}^{5}w_iZ(x_i)\right)\] \[(1,7) \rightarrow (-3,3)\rightarrow (-3w, 3w) \rightarrow (-3, 3) \rightarrow (0, 100)\] But, we only have scaled data (in the range of 0-100)

Dr. Jain: “a constrained optimization model that minimizes variances from the published ranking”

Model

\[y = w_1x_1 + w_2x_2 + w_3x_3 + w_4x_4 + w_5x_5 + \epsilon\] with \(\sum_i w_i = 1\) and \(w_i \geq 0\). Then minimize

\[\sum_i (y_i - (w_1x_1 + w_2x_2 + w_3x_3 + w_4x_4 + w_5x_5))^2\]

Quadratic Optimization

This problem is a quadratic optimization problem and it is well studied in mathematics
